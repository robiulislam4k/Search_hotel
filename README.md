# 🏨 Hotel Booking Website Testing – PHPTravels

## 📌 Project Overview
This project involves **end-to-end manual testing** of the PHPTravels hotel booking website to validate booking functionality, user workflows, and UI behavior.

🔗 Website: https://phptravels.net/hotels  
🔗 Repository: https://github.com/robiulislam4k/Search_hotel  

---

## 🧪 Testing Scope
The following features were tested:

- Hotel Search & Filters
- Hotel Details Page
- Booking Form Validation
- Payment Process
- Invoice Generation
- UI & Navigation Flow

---

## 🔍 Types of Testing Performed
- Functional Testing  
- End-to-End Testing  
- UI/UX Testing  
- Validation Testing  

---

## 🛠️ Tools Used
- Manual Test Cases & Scenarios  
- Bug Documentation using GitHub  
- Browser Testing Tools  

---

## 🐞 Issues Identified
- UI inconsistencies  
- Validation errors in booking forms  
- Functional issues during booking flow  

---

## ✅ Outcome
This project helped ensure a reliable booking experience by identifying usability, functional, and validation issues across the application.
